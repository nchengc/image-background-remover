### 文档关系与锁定决策（必读）
本文档是收口版，与 PRD、系统架构设计保持一致，但**以如下用户拍板决策为准，不推翻**：
1. **抠图 API = remove.bg**（非阿里云；注册即得 Key，无需实名认证）
2. **部署 = Cloudflare Pages + Pages Functions**（零成本、免备案、同源代理）
3. **图片不落盘**：函数收图即处理即返，纯内存，不写任何存储
4. **范围 = P0 + P1 完整极简版**

> 注：原 PRD 曾推荐「阿里云通用分割」，本次按用户拍板改为 remove.bg。系统架构设计已采用**可插拔 Provider**（`BackgroundRemovalProvider` 接口 + `getProvider(env)` 工厂），默认启用 `removebg` 仅需设置 `PROVIDER=removebg` + `REMOVE_BG_API_KEY`，**无需改代码**，故三方文档不冲突。

## 1. MVP 定义与目标

### 1.1 一句话 MVP 定义
一个**零注册、零付费（演示期）、秒级**的在线图片去背景极简工具：用户上传图片 → 经同源 Serverless 代理调用 remove.bg → 预览透明 PNG → 一键下载，核心闭环一步到位。

### 1.2 可衡量成功标准
| 编号 | 成功标准 | 衡量方式 |
|---|---|---|
| SC1 | **易用且快**：新用户从打开页面到拿到去背结果 ≤ 30 秒（含上传 + 处理 + 预览），无需任何引导教程 | 实测一次完整流程耗时（演示网络环境） |
| SC2 | **质量可接受**：常见场景（人像 / 商品 / 宠物）下边缘干净、主体无残留背景 | 抽查 5–10 张典型图，肉眼确认无大块背景残留 |
| SC3 | **成本可控**：演示 / 验证期（≤ 50 图 / 月）API 与托管成本 ≈ 0 元 | remove.bg 免费档（50 预览 / 月）+ Cloudflare 免费档 |

## 2. 目标用户与典型场景

**用户画像**：设计行业从业者、电商小卖家、普通电脑 / 手机用户；非技术背景、追求即用即走、不愿注册或付费。

| 编号 | 用户故事 |
|---|---|
| US1 | 作为**设计从业者**，我希望拖一张图进网页就能自动去背，以便快速拿到透明素材用于设计稿，而不用打开 Photoshop 手动抠。 |
| US2 | 作为**电商小卖家**，我希望上传商品图后得到透明 PNG，以便后期自由换背景、做海报，而不必购买昂贵修图软件。 |
| US3 | 作为**普通用户**，我希望处理完能直接预览（原图 vs 去背图）并确认效果满意再下载。 |
| US4 | 作为**非技术用户**，我希望整个过程不需要注册登录，以便即用即走、不泄露隐私。 |
| US5 | 作为**移动端用户**，我希望在手机浏览器里也能上传、预览、下载，以便随时处理图片。 |

> P2「换背景」相关故事本轮**不纳入**（见第 7 节范围边界）。

## 3. 功能需求（分层）

### 3.1 P0（必须有）

| 编号 | 描述 | 验收标准 |
|---|---|---|
| **P0-1** 上传 | 支持**点击 / 拖拽**上传本地图片，接受 JPG / PNG / WEBP，限制 ≤ 10MB；拖拽时上传区高亮 | 拖入或选择图片后立即进入原图预览；非允许类型或 >10MB 立即报错并**阻止**进入处理；拖拽悬停有视觉反馈 |
| **P0-2** 代理去背 | 前端 `POST /api/remove-bg`（同源）提交图片；Cloudflare Pages Function 持有 `REMOVE_BG_API_KEY` 调用 remove.bg，返回**透明 PNG 二进制**；Key 绝不经前端 | 前端 bundle / 请求中**无任何 API Key**；同源部署消除 CORS；成功响应 `Content-Type: image/png` 且含 alpha 透明通道；失败返回结构化错误 JSON |
| **P0-3** 预览 | 结果以**棋盘格背景**衬托透明区域展示；可与原图**切换**查看 | 透明区透出棋盘格；点击可在原图 / 结果间切换；并排对比见 P1-2 |
| **P0-4** 下载 | 提供「下载透明 PNG」按钮，导出原始分辨率透明 PNG | 点击下载 `.png`，透明通道保留（图片查看器验证）；文件名含 `_nobg` |
| **P0-5** 四态反馈 | `idle / loading / done / error` 四态；`loading` 禁用重复提交；`error` 可重试、不白屏 | `loading` 时所有上传入口 disabled；`error` 显示友好中文文案 + 重试按钮（复用 `lastFile`）；任意失败路径均进入 error 态，不白屏 |

### 3.2 P1（应该有）

| 编号 | 描述 | 验收标准 |
|---|---|---|
| **P1-1** 粘贴上传 | 支持 **Ctrl+V** 粘贴剪贴板图片直接上传 | 页面焦点内粘贴图片即触发上传校验流程 |
| **P1-2** 对比视图 | 提供**原图 vs 去背图**并排 / 滑杆对比（纯前端，零成本） | 可拖动滑杆或切换查看前后对比；不增加后端负担 |
| **P1-3** 限流 / 超时 / 并发 | 代理层：① `Promise.race` **30s 超时**；② 内存信号量**并发 ≤ 2**（isolate 级软限流）；③ 超限返回 `429` 可重试 | 第三方 >30s 走 `TIMEOUT(504)`；并发满返回 `RATE_LIMITED(429)`；均为可重试错误 |
| **P1-4** 移动端适配 | 页面在手机浏览器可用（上传 + 预览 + 下载） | 主流移动视口（iOS Safari / Android Chrome）布局不溢出，按钮可点 |

## 4. 非功能需求

| 类别 | 要求 |
|---|---|
| **性能** | 新用户打开到拿到结果 ≤ 30s（含上传 + 处理 + 预览）；静态首屏加载 < 3s（Cloudflare 全球 CDN）；处理依赖第三方，演示环境网络尾延迟可能 +1–3s（见风险 4），SC1 仍成立 |
| **成本** | 演示期（≤ 50 图 / 月）≈ 0：remove.bg 免费 50 预览 / 月 + Cloudflare 免费档；超出按约 $0.20+/张计费（非 MVP 关注点） |
| **隐私** | 图片**不落盘**，函数收即处理即返、纯内存；页脚声明「图片仅在去背时上传，处理完即丢弃，不存储」；API Key 仅存于函数环境变量 |
| **兼容性** | 现代浏览器（Chrome / Edge / Firefox / Safari 近两版本）+ 移动端；输入支持 JPG / PNG / WEBP；输出透明 PNG |
| **可维护性** | Provider **可插拔**（`BackgroundRemovalProvider` 接口）；切回阿里云等仅需改 `PROVIDER` 环境变量 + 配 Key，不改业务代码；前端与代理同平台同源；TypeScript 契约约束接口与状态机 |

## 5. 关键用户流程

### 5.1 主路径（上传 → 处理 → 预览 → 下载）
```
用户打开页
  → 上传（点击 / 拖拽 / 粘贴）
  → 前端校验（类型 / 大小）         [失败 → 前端即时报错，不发起请求]
  → POST /api/remove-bg（同源 multipart）
  → 代理：二次校验 + CORS + 信号量(≤2) + 取 remove.bg Key
  → 调 remove.bg API（size=auto）
  → 返回透明 PNG 二进制
  → 前端 blob + 棋盘格预览 + 下载按钮
```

### 5.2 分支（错误 / 重试 / 换图）
| 触发 | 行为 |
|---|---|
| 前端校验失败（类型 / 大小） | 即时报错，不发起请求 |
| 后端校验失败（415 / 413） | 返回错误 JSON → `error` 态，提示换文件（不可重试） |
| 超时（> 30s） | `TIMEOUT(504)` → `error` 态，可重试 |
| 并发已满（≥ 2） | `RATE_LIMITED(429)` → `error` 态，可重试 |
| 第三方 / 内部错误（502 / 500） | `error` 态，可重试 |
| 用户换图 | `done` / `error` → `RESET` → `idle`（清空，重新上传） |

> 任何失败分支均进入 `error` 态并渲染**重试按钮**，加载态禁用全部提交入口，杜绝重复提交与白屏。

## 8. 上线清单 / 里程碑

### 8.1 本地联调步骤
1. **前置**：注册 remove.bg 账号，获取 API Key。
2. **配置环境变量**（本地 `.dev.vars` 或 wrangler 本地配置）：
   ```
   REMOVE_BG_API_KEY=xxxx          # 必填，仅服务端
   PROVIDER=removebg               # 默认即 removebg
   MAX_CONCURRENCY=2
   PROVIDER_TIMEOUT_MS=30000
   ALLOWED_MAX_MB=10
   ALLOWED_TYPES=image/jpeg,image/png,image/webp
   ```
3. 启动前端（`npm run dev`）+ 函数（`wrangler dev`）。
4. 用一张本地图跑通：上传 → 预览（棋盘格）→ 下载透明 PNG。

### 8.2 Cloudflare Pages 部署步骤
1. 构建：`npm run build` → 产物 `dist/`。
2. 部署：git push 触发构建，或 Cloudflare Dashboard 上传 `dist/`。
3. 在 Pages 项目 **Settings → Environment variables** 配置上述变量（尤其 `REMOVE_BG_API_KEY`）。
4. 绑定 Pages Functions（仓库 `functions/` 目录自动识别）。
5. 验证 `*.pages.dev` 子域可公开访问。

### 8.3 验证项（上线前 Checklist）
- [ ] 点击 / 拖拽 / 粘贴三种上传方式均可用
- [ ] 非法类型 / 超大文件有明确报错
- [ ] 正常去背 + 棋盘格预览 + 下载透明 PNG
- [ ] 并发 / 超时 / 第三方错误均走 `error` 态 + 重试，不白屏
- [ ] 移动端视口布局正常
- [ ] 隐私页脚声明可见

## 9. 风险与待办

| 编号 | 风险 / 待办 | 说明与缓解 |
|---|---|---|
| R1 | **remove.bg 免费档为低分辨率预览图** | 免费 50 次 / 月为预览分辨率；高分辨率需付费 credit（约 $0.20+/张）。SC3（演示期≈0）仅在 ≤50 预览图 / 月成立。演示期足够，正式运营需预算 |
| R2 | **并发 ≤ 2 为 isolate 级软限流，非全局硬限流** | 信号量按函数实例生效；高并发多实例下总并发可能 >2。严格全局限流需 KV / Redis（列为后续增强，非 MVP）。演示流量低，风险可控 |
| R3 | **需用户自备 remove.bg API Key** | Key 仅存函数环境变量，前端不可见；泄露风险靠「仅服务端 + 不进 bundle」规避 |
| R4 | **大陆访问 Cloudflare 偶发慢** | Cloudflare 海外边缘 → remove.bg，单图网络尾延迟可能 +1–3s。SC1（≤30s）仍成立，但已与用户确认该延迟预期可接受；生产稳定大陆访问可迁阿里云 FC（可插拔设计支持） |
| R5 | **架构文档默认项待对齐**（非阻塞待办） | `system_design.md` 第 5 节仍写「默认阿里云通用分割」；建议在架构文档补一行：「MVP 锁定 remove.bg，通过 `PROVIDER=removebg` 启用，可插拔设计无需改代码」。不影响开工 |
